# Provenance & Epistemic Model

> **Status**: `FROZEN v1.0.0`  
> **Epistemic Classification**: Truth Tiers and Boundary Rules

---

## 1. Epistemic Status Tiers

The system distinguishes between five formal epistemic tiers:

| Status Tier | Definition | Source of Truth |
|:---|:---|:---:|
| **GIVEN** | Initial axiomatic problem data, coordinate baselines, and free parameters. | External Problem Statement |
| **HYPOTHESIS** | Conjectured relationships proposed by an AI agent before formal verification. | External Reasoning Model |
| **TOOL-VERIFIED** | Relationships evaluated by the Geometry Core within fixed threshold $\varepsilon = 10^{-4}$. | Geometry Kernel SSOT |
| **DERIVED** | Points, segments, and metrics generated by deterministic algebraic reduction. | Geometry Reducer |
| **INVALID** | Relationships formally falsified by verification exceeding threshold $\varepsilon = 10^{-4}$. | Verification Engine |
| **VANISHED** | Truth decay state when underlying geometric preconditions are broken. | Internal Knowledge Graph |

---

## 2. Epistemic Separation Boundary

External agents must enforce the three-tier separation:

$$\text{TOOL-VERIFIED FACT} \neq \text{AGENT INTERPRETATION} \neq \text{AGENT HYPOTHESIS}$$

- **Tool Fact**: *«Segment CA is perpendicular to segment AB within tolerance 1e-4.»*
- **Agent Interpretation**: *«Therefore, triangle ABC is right-angled at vertex A.»*
- **Agent Hypothesis**: *«Therefore, the circumcenter lies on the midpoint of BC.»*

---

## 3. Provenance Tracking

Entities track structural lineage via `observe('PROVENANCE')`:
- `targetId`: Unique machine ID of the entity.
- `sourceIds`: Parent entities that generated this object.
- `macroType`: Generator macro classification (`perpendicular`, `angle_bisector`, etc.).
- `groupId`: Transactional group identifier linking coupled entities.
- `role`: Functional classification (`primary`, `auxiliary`).
