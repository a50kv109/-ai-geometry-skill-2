# TSL-05 Research Task: Harmonic Sensitivity

## Objective
Analyze the relationship between harmonic count and geometric reconstruction error for a set of standardized shapes.

## Procedure
1. Define a set of shapes:
    - Equilateral Triangle
    - Square
    - Circle
2. For each shape, run the CLI tool for harmonic values $h \in \{1, 2, 4, 8, 16\}$.
3. Record the resulting `maxError`.
4. Plot or tabulate the sensitivity of error to harmonic reduction.

## Expected Outcome
A report detailing the minimal harmonic set required to maintain a reconstruction error below a threshold (e.g., 0.05).
