# AI Geometry Research Methodology

> **Target Audience**: AI Coding Agents, Mathematical Reasoning Models  
> **Core Principle**: `REASON OUTSIDE. VERIFY INSIDE.`  
> **Experimental Loop**: Observation ➔ Candidate ➔ Hypothesis ➔ Falsification ➔ Zero-Trust Verification

---

## 1. The Research Protocol

When using AI Geometry Skill as an autonomous research instrument, follow this 6-stage scientific protocol:

```
  1. CONSTRUCTION
  Build clean base geometry using primitive actions.
         │
         ▼
  2. CONTROLLED MUTATION
  Execute at least 5 varied configurations (symmetric, asymmetric,
  oblique, close-proximity, and boundary/tangency cases).
         │
         ▼
  3. MEASUREMENT & OBSERVATION
  Collect numerical metrics via measure() and topological state via observe().
         │
         ▼
  4. HYPOTHESIS FORMATION
  Identify persistent numerical and relational invariants across configurations.
         │
         ▼
  5. COUNTEREXAMPLE SEARCH (FALSIFICATION)
  Actively attempt to break the hypothesis (tilt lines, reverse vectors,
  deform shapes). If broken, restrict boundary conditions.
         │
         ▼
  6. ZERO-TRUST INDEPENDENT VERIFICATION
  Export verified invariant to GSA v0.1. Import into an independent,
  clean session to confirm acceptance by an external Stand.
```

---

## 2. Experimental Discipline & Layer Separation

- **Coordinate Mutation $\neq$ Topological Change**: Moving a point mutates its coordinates, but does not alter incidence relations unless explicitly re-intersected.
- **Affected $\neq$ Broken**: A moving parent line causes its previous intersection points to lose coincidence, but the points themselves remain in existence.
- **Conscious Refusal**: If a task does not involve formalizable planar geometry, refuse invocation (`DRA = NO`). If a required property is unsupported, output `CAPABILITY GAP / NOT REPRESENTABLE`.
